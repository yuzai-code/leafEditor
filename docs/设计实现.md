## 项目思路

### web 端

直接请求后端接口，后端接口返回数据，前端进行展示。只支持在线查看

### 桌面端

使用 tauri 进行开发，使用 SQLite 作为数据库，使用 SQLite WASM 作为数据库的实现，使用 Vue 3 作为前端框架，使用 Tailwind CSS 作为 CSS 框架。
**功能**

- 支持离线查看
- 支持离线编辑

## 数据存储

- 所有数据都存储到服务器中采用端对端加密
- web端直接请求后端接口，后端接口返回数据，前端进行展示。只支持在线查看
- 桌面端使用sqlite本地存储，并进行端对端加密，采用同步机制，保证数据的一致性
